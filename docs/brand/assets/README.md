# Hypertext Studio Wordmark Assets

`wordmark.svg` uses Ink. `wordmark-paper.svg` uses Light Ink for dark backgrounds. Both contain outlines from IBM Plex Mono Regular with −0.03em tracking and preserve the same geometry.

The view box follows the visible artwork bounds. Add clear space outside the artwork equal to at least one lowercase x-height: approximately 5.1% of the rendered wordmark width on each side. Preserve the aspect ratio.

The compact bracket icon is generated by `scripts/icons.sh`.
