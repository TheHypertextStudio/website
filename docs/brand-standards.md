# Hypertext Studio Brand Standards

Identity, assets, and usage for studio communications and product credits.

## Brand overview

### Name

Write **Hypertext Studio** in prose, headings, and credits. Use **hypertext.studio** for the website address. After the full name has appeared, “the studio” is a natural reference.

Preserve the product names **Docket**, **LogDate**, **Curfew**, and **Athena**. Describe Athena in relation to Docket where relevant.

### Studio statement

> Hypertext Studio builds software for humans.

Use this as the primary studio statement. When a reader needs more context, use the company description:

> Hypertext Studio is a software studio behind Docket, LogDate, and Curfew.

### Brand character

Clear, thoughtful, and curious. Express the connection to hypertext through readable information, useful links, and visible destinations.

## Logo

### Wordmark

The wordmark is **`<hypertext-studio>`**. Keep the lowercase name, hyphen, and angle brackets together on one line.

| Property              | Standard                                      |
| --------------------- | --------------------------------------------- |
| Typeface              | IBM Plex Mono Regular, weight 400             |
| Tracking              | −0.03em                                       |
| Color                 | Ink on Paper; Light Ink on Dark Paper         |
| Clear space           | At least one lowercase x-height on every side |
| Minimum digital width | 160 px                                        |

Use the supplied artwork:

- [Ink wordmark](brand/assets/wordmark.svg) for light backgrounds.
- [Light Ink wordmark](brand/assets/wordmark-paper.svg) for dark backgrounds.

Add clear space outside the artwork; the SVG bounds do not include it. Preserve its proportions. Use the plain studio name when space cannot accommodate the full mark.

### Compact symbol

Use the angle-bracket symbol for favicons, avatars, and small placements. Keep a readable studio name nearby when context is needed.

### Logo usage

Place marks on a clear field. Keep surrounding text and edges outside their clear space. Never stretch, wrap, or recolor the studio mark with product accents.

Use `</hypertext-studio>` to close a page or document after the primary wordmark or full name has appeared.

## Typography

### Font roles

| Family        | Use                                       | Weight                                   |
| ------------- | ----------------------------------------- | ---------------------------------------- |
| Inter         | Headings, prose, navigation, and credits  | 400 body; 500–600 headings; 600 emphasis |
| IBM Plex Mono | Wordmark, addresses, references, and code | 400                                      |

Inter is the default. Use IBM Plex Mono for the wordmark, addresses, references, and code.

### Type scale

Use this starting hierarchy for digital studio materials. Adapt the scale to the medium and available space.

| Role                 | Size     | Line height |
| -------------------- | -------- | ----------- |
| Display              | 48–96 px | 1.05        |
| Page title           | 32 px    | 1.15        |
| Section heading      | 24 px    | 1.25        |
| Body                 | 16–18 px | 1.5–1.6     |
| Caption or credit    | 14–16 px | 1.5         |
| Address or reference | 13–14 px | 1.5         |

### Reading and hierarchy

Use sentence case for headings. Establish hierarchy through size, weight, and space. Keep body paragraphs around 55–75 characters per line and body text readable at the intended viewing size.

## Color palette

### Primary colors

Warm neutrals carry the studio identity.

| Appearance | Canvas               | Text and wordmark   |
| ---------- | -------------------- | ------------------- |
| Light      | Paper `#FBFBFA`      | Ink `#25231F`       |
| Dark       | Dark Paper `#181713` | Light Ink `#F3F3ED` |

### Supporting colors

| Role               | Light     | Dark      |
| ------------------ | --------- | --------- |
| Secondary text     | `#666666` | `#AAA99F` |
| Supporting surface | `#F1F2EE` | `#1A1B17` |
| Divider            | `#DDDDDA` | `#373832` |
| Links and focus    | `#1646D8` | `#91ADFF` |

Blue identifies interactions. Keep a product's accent with that product.

### Contrast and links

Keep ordinary text contrast at least 4.5:1 against its background. Underline inline text links. Section headings link to their own anchors and reveal a hash on hover or focus.

Use dividers and surface changes to organize content. Essential information also needs a readable label or other clear cue.

## Imagery and layout

### Composition

Give each composition one main subject. Align the studio identifier, subject, and destination through a clear grid and deliberate space.

A studio announcement can place the wordmark above the subject, with a short annotation and useful destination beside or beneath it. Include an annotation when it helps explain the subject.

Use real destinations. A studio introduction links to `hypertext.studio/#products`; a product announcement links to the product's site.

Start digital layouts with an 8 px spacing rhythm, using 4 px for small adjustments. Set margins to suit the content and medium.

### Imagery

- Use real product assets and legible screenshots.
- Use ASCII illustration for recognizable subjects.
- Keep decorative artwork separate from readable text. Describe images that carry information.

Use brackets and addresses where they identify or connect something.

### Motion

Use motion to clarify a transition or response. Preserve the information in a static version and respect reduced-motion settings.

## Voice and tone

Say what the studio or product does. Use direct instructions, concrete nouns and verbs, and claims supported by the software.

Use “we” when the studio speaks. Use the company name when another organization or product describes it. Address the reader as “you” when it makes an explanation clearer.

| Context          | Wording                                |
| ---------------- | -------------------------------------- |
| Support          | Email hello@hypertext.studio for help. |
| Unavailable page | There's no page at this address.       |

Explain privacy and reliability through specific behavior. Avoid unsupported superlatives and promises.

## Product attribution

| Context                            | Credit                        |
| ---------------------------------- | ----------------------------- |
| Default                            | Made by Hypertext Studio      |
| Tight space beneath a product name | by Hypertext Studio           |
| Descriptive prose                  | A product of Hypertext Studio |

Link the studio name to [hypertext.studio](https://hypertext.studio). Use the application's own typeface and readable text color. Keep the product name primary and the credit at the supporting text size, normally at least 14 px.

A credit can use the plain studio name:

> LogDate  
> Made by Hypertext Studio
